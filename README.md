# LUMOSYNC

ESP32 LED 点阵灯板控制器 · Flutter 双端(Android / iOS)

通过蓝牙(BLE)控制车用 LED 点阵屏:特效、车灯模式、图片、GIF 动画、滚动文字、音乐律动。

## 功能

**四个主页面**

| 页面 | 内容 |
|---|---|
| 控制 | 连接状态、灯板实时预览、电源/亮度、快捷场景 |
| 场景 | 场景库、播放列表自动轮播、保存当前状态 |
| 创作 | 像素编辑器、图片转点阵、GIF 动画、滚动文字 |
| 车灯 | 位置灯 / 刹车 / 转向 / 倒车 / 双闪 / 迎宾 |

**特效引擎** — 12 种:彩虹、呼吸、流星、火焰、等离子、星点、波浪、水波、扫描、旋转色轮、雨滴、纯色。5 套调色板。

App 端与固件端使用**完全相同的渲染算法**,所以手机里预览到的就是灯板上跑出来的。

## 架构要点

**特效在设备端渲染,App 只下发参数。**

原因:
1. BLE 带宽跑不动逐帧推流
2. 车开走、手机不在身边时,灯必须照常工作

只有图片 / 动画 / 文字位图这类无法用公式生成的内容才上传像素数据。

**通信协议**

```
[0xA5][OP][LEN_hi][LEN_lo][payload...]
```

BLE 走 Nordic UART 服务,数据按 MTU 分片;固件端用状态机重组。
WiFi(TCP)可选,用同一套封包,给大数据传输用 —— 默认关闭,蓝牙已够用。

| OP | 名称 | 说明 |
|---|---|---|
| 0x01 | TEXT | ASCII 调试命令 |
| 0x02 | FRAME | 整帧像素(物理顺序 RGB) |
| 0x03 | BRIGHT | 全局亮度 |
| 0x04 | CONFIG | 灯板尺寸与走线方向 |
| 0x05 | EFFECT | 效果编号 + 参数 |
| 0x06 | TAILLIGHT | 车灯模式 |
| 0x07~09 | ANIM_* | 动画上传与播放 |
| 0x0A | SCROLL | 滚动文字位图 |
| 0x0B | POWER | 开 / 关 |

## 项目结构

```
lib/
├─ ble/          BLE 与 WiFi 传输、协议封包
├─ models/       点阵、特效、尾灯、文字渲染、音频 FFT、场景数据
├─ screens/      11 个页面
├─ widgets/      通用组件、灯板预览、设备选择
├─ state/        全局状态与下发逻辑
└─ theme.dart    深色紫粉玻璃拟态配色
```

## 开发

```bash
flutter pub get
flutter run
```

**注意:蓝牙必须真机调试**,模拟器没有蓝牙硬件。

安卓需要授予**蓝牙 + 位置**权限(BLE 扫描强制要求定位权限)。

## 配套固件

ESP32 端固件(Arduino)见另一个项目 `lumos_esp32`,需要 FastLED 库,
Partition Scheme 选 **Huge APP**(蓝牙 + WiFi 同时用,默认分区不够)。

## iOS 构建

无 Mac 时通过 Codemagic 云端构建,配置见 [codemagic.yaml](codemagic.yaml)。
